# Lista de Contatos - M32

Projeto desenvolvido em React com Redux Toolkit e Styled Components.

## Funcionalidades

- adicionar contato;
- editar contato;
- remover contato;
- dados: nome completo, e-mail e telefone.

## Executar o projeto

```bash
npm install
npm start
```

## Build de produção

```bash
npm run build
```
